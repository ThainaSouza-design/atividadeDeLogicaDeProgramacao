# 🧠 Atividade de Lógica de Programação

Este repositório contém a resolução de uma lista de **10 exercícios de Lógica de Programação**, desenvolvidos com o objetivo de praticar estruturas fundamentais da programação, raciocínio lógico e resolução de problemas utilizando **JavaScript**

Ao longo da atividade, foram aplicados conceitos como operações matemáticas, estruturas condicionais, laços de repetição, vetores, ordenação e manipulação de dados.

---

## 📚 Exercícios desenvolvidos

### 1️⃣ Cálculo do custo final de um carro

Programa que calcula o custo final de um carro ao consumidor considerando o custo de fábrica, a porcentagem do distribuidor e os impostos.

### 2️⃣ Salário de vendedor de automóveis

Programa que calcula o salário final de um vendedor com base no salário fixo, comissão por veículo vendido e percentual sobre o valor total das vendas.

### 3️⃣ Conversão de temperatura

Conversão de temperatura de graus Fahrenheit para graus Celsius utilizando a fórmula matemática correspondente.

### 4️⃣ Compra de maçãs

Programa que calcula o valor total da compra de maçãs aplicando preços diferentes conforme a quantidade adquirida.

### 5️⃣ Maior entre dois números

Leitura de dois valores e exibição do maior deles utilizando estruturas condicionais.

### 6️⃣ Duração de uma partida de xadrez

Cálculo da duração de uma partida considerando que ela pode terminar no dia seguinte, respeitando o limite máximo de 24 horas.

### 7️⃣ Soma dos dois maiores valores

Leitura de três números diferentes e cálculo da soma dos dois maiores.

### 8️⃣ Soma dos números pares

Programa que calcula o somatório de todos os números pares no intervalo de 1 até 500 utilizando laços de repetição.

### 9️⃣ Vetor de nomes

Cadastro de 20 nomes em um vetor, ordenação em ordem alfabética e pesquisa de um nome informando sua posição no vetor.

### 🔟 Verificação para aposentadoria

Sistema que verifica se um funcionário está apto para solicitar aposentadoria com base na idade e no tempo de serviço, conforme regras estabelecidas.

## 🎯 Objetivo da atividade

O principal objetivo desta lista foi fortalecer a lógica de programação por meio da resolução de exercícios envolvendo situações do cotidiano, desenvolvendo o raciocínio lógico e preparando a base para conteúdos mais avançados, como Programação Orientada a Objetos e desenvolvimento de aplicações.
